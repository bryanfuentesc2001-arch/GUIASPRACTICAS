DBM Studio — Privacy Policy

Last updated: October 31, 2026

DBM Studio is a personal tool used only by its owner, Bryan Fuentes, on his own computer, for his own YouTube channels.

Data accessed

With the owner's permission (Google OAuth), DBM Studio accesses the owner's YouTube channels through the YouTube Data API: it uploads videos, thumbnails and captions, and reads and replies to comments on those channels.

Storage

OAuth tokens and comment lists are stored only on the owner's computer. Nothing is sent to any server owned by DBM Studio (there is none), sold, shared or used for advertising.

Third parties

Comment texts may be processed by the owner's AI assistant to draft replies, which the owner reviews before posting. No data is shared with anyone else.

Google API Services

DBM Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions; local data is deleted with the "Disconnect" button in DBM Studio.
